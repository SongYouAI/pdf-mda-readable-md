# pdf-mda-readable-md

> **年报「董事长致辞 + 管理层讨论与分析」→ 可读中文 Markdown 抽取器**

把一堆年报 PDF（A 股 / 港股，简体 + 繁体混排）里的**定性叙述章节**——
「董事长致辞 / 主席報告 / 致股东」与「管理层讨论与分析 / 董事會報告 / 業務回顧」——
自动定位、抽取，并**重整为 AI 好读的中文结构化 Markdown**。

它不是又一个「把整本 PDF 倒成文本」的通用转换器，而是**专门为一手年报这种
长、结构化、双语的文档打磨的抽取器**：读得懂章节边界，处理得了港股双语双栏，
修得了年报特有的页眉 / 页码 / 勾选框 / 装饰水印，最后还自带质量验收闭环。

## 这是什么

一家上市公司每年会发布：

- **年度报告**（含「董事长致辞 / 主席報告」与「管理层讨论与分析 / 董事會報告」）
- **招股说明书 / 招股书**
- 各种**可持续发展报告、ESG 报告、临时公告**

这些文件绝大多数是 **PDF**。本 skill 的目标只有一个：
把其中**最值得被 AI / 检索系统阅读的定性叙述部分**抽出来，变成干净的 Markdown。

产出形态（以华能国际为例）：

```
01-发电运营（15家）/02_华能国际/董事长致辞与MD&A/华能国际_2023_董事长致辞与MD&A.md
```

每一份年报 = 一个独立 MD 文件，文件头标注源 PDF 文件名与页码范围（可回查原 PDF）。

## 为什么要把年报 PDF 转成 Markdown（格式转换的必要性）

**一句话：PDF 是给人「看」的，Markdown 是给 AI「读」的。**

### PDF 对 AI / RAG / Agent 并不友好

PDF 是为**打印和屏幕显示**设计的版式格式，它的内部结构是「坐标 + 字形」，
而不是「段落 + 标题 + 表格」。当你（或你的 Agent）把一份年报 PDF 直接喂给大模型时，
实际拿到的文本层通常是这样的：

1. **断行碎片**：正文被 PDF 按版心宽度切成一行 30–50 字的碎片，
   一句话被硬生生断成 3–4 行，「公司实现营业」和「收入同比…」被拆开。
   大模型读起来支离破碎，摘要和抽取都会失真。
2. **没有段落结构**：换行 ≠ 分段。AI 无法判断哪里是一段结束、哪里是新段开始。
3. **双语污染（港股尤其严重）**：港股年报是中英**双栏**排布。直接抽文本层会把
   英文栏整栏一起喂进去，一份「主席報告」里混进大段 `Our principal operations…`，
   严重污染中文语料，也让 embedding / 检索向量变脏。
4. **版式家具混进正文**：页码（`12` / `X / Y`）、章节运行页眉（`管理層討論與分析`）、
   `√适用 □不适用` 勾选框、报告标题里的年份、证券代码、URL、上接/下转标记……
   这些对「读懂内容」毫无用处，却大量挤占上下文。
5. **坐标噪声**：PDF 文本层带 `x0 / y0 / size` 等坐标信息，对 AI 没用，反而干扰。

> 实测：某港股年报直接抽文本层，单份里就有 **100+ 行整页英文残留、289 张页面被
> 装饰框误判成「整页假表」导致整页正文丢失**。这种原始产物，AI 根本读不动。

### 转成 Markdown 之后，AI 读起来方便很多

- **段落被合并、标题被分层**（`####` / `#####`）：语义结构清晰，大模型能正确分段、正确归纳。
- **只保留中文**（港股去英文栏）：语料干净，做 embedding / 检索 / 问答时命中更准、噪声更低。
- **表格被还原成 Markdown 表格**：数字对齐、可复制、可被表格解析器直接吃。
- **轻量、可 diff、可进 git**：MD 是纯文本，版本可控、可 review、可被任何
  Markdown reader、RAG 框架、静态站点直接消费。
- **可回查**：每份 MD 头标注源 PDF 文件名 + 页码范围，AI 的结论能追溯到原文。

**所以：年报 / 招股书这类长文档，AI 直接读 PDF 效果差；导成 Markdown 之后，
AI 读起来方便很多，后续做检索、问答、对比、摘要都顺手。** 这就是格式转换的必要性。

## 本 skill 的优势（为什么不用通用 PDF→MD 工具）

通用 PDF→MD 工具有很多：`pandoc`、`pdfplumber` 裸转、各种在线转换器……
它们**在「整本无差别文本流」上能跑，但在「从 A 股 / 港股年报里提取信息」这个场景上都不够用**。

### 通用工具的痛点

| 场景 | 通用工具的表现 |
|---|---|
| 章节边界 | 把整本 PDF 当无差别文本，不区分「董事长致辞」和「财务报表」，你需要自己再切 |
| 港股双语双栏 | 中英文一起倒出来，**英文残留**严重，污染语料 |
| 年报页眉 / 页码 / 勾选框 | 全部混进正文，Ai 读到一堆噪声 |
| 复杂表格 | `find_tables()` 把年报大表识别成**单列**，比原文还难读，或直接崩 |
| 装饰框 / 裁切线 | 被误判成「整页表格」，导致**整页正文丢失**（最隐蔽的坑） |
| 段落 | 按行距硬切，中文年报段内假断、段间漏断 |

### 本 skill 为什么更合适

它的每一个启发式，都是**在真实战场上一行行磨出来的**：

> 沉淀自电力行业研究实战——**20 家上市公司 / 196 份年度报告，A 股 + 港股，简体繁体混排**。
> 它读过非常多非常多不同的 A 股和港股年报，针对「从 A 股和港股的 PDF 年报中提取信息」
> 这个具体场景做了大量专门调优，因此比一般的 PDF→MD skill 更适合这种结构化年报。

具体强在哪：

1. **真懂年报的章节结构**
   - 同时识别 A 股「第 X 节」与港股繁体「第 X 節」（一个字符类 `[节節]` 的坑就踩过）；
   - 跳过目录页（含港股特有的「页码在前」目录格式 `10主席報告`）；
   - 自动防「董事长致辞」与「管理层讨论与分析」章节重叠（港股双报告合并扉页）；
   - 港股裸页眉命中时取本页首个编号节作章节号，避免后续同号页眉被误判成新边界、把章节截断。

2. **真懂港股双语双栏的去英文**
   - 不是简单「删掉英文行」，而是**按栏切分**（扫候选切分线取跨线词最少者），
     再用「两侧各 ≥8 词」的平衡判据保留中文栏；
   - 关键：**去英文做「行级 + 段级」两次**——行级挡不住并段拼接出的英文，
     必须合并段落后再筛一遍，否则 `eti` + `Re dso` 拼成 `etiRe dso` 残留在正文里。

3. **真懂中文年报的段落逻辑**
   - 分段**以首行缩进为主、行距为辅**（中文靠缩进分段，不能只靠行距，否则段内假断）；
   - **左边距取正文 x0 的众数，绝不取 min**（港股页脚比正文更靠左，取 min 会把每页炸成 19 段）；
   - 跨栏 / 跨页断段会自动并回。

4. **修得了年报特有的脏数据**
   - **幻影表拒绝**：装饰框越出页面 >5pt、或退化单列、或网格误判 → 一律拒收，让文字回落正文；
   - **logo 水印剔除**：公司 logo 字母沿曲线排布，逐字读出成 `o華ur潤ce電s`、
     `g s C o m p a n y L i m i t e d`，用「中↔英交错」+「孤立单字符成串」双判据清掉；
   - **反序页眉 / 字符三连叠印修复**：页眉旋转 180° 导致 `報年5202`、`董董董事事事長長長`，
     倒读 + ≥3 连续同字判据修复（且绝不用 ≥2，避免误删 `国电电力` 这类合法专名）。

5. **自带质量验收闭环**
   - `audit_md_quality.py` 一键批量质检：**英文残留行 / 反序页眉 / 字符重复 / 纯符号行 / 结构覆盖**
     五项硬伤，全库 0 才算过关。198 份年报实战跑下来，五项全 0。

**结论**：通用工具把年报当「任意 PDF」；本 skill 把年报当「年报」——
它更懂章节、更懂双语、更懂中文段落、更懂年报特有的脏数据，
产出**直接可用于 RAG / 检索 / 对比分析**，而不是一堆需要二次清洗的碎片。

## 快速开始

### 依赖

- Python 3.9+
- `pymupdf`（页区检测）
- `pdfplumber`（可读化重整）

装于 WorkBuddy managed venv 时：

```bash
PY=/Users/niusl321/.workbuddy/binaries/python/envs/default/bin/python
$PY -m pip install pymupdf pdfplumber
```

### 目录约定

把年报 PDF 按如下结构放好（本仓库的 `references/` 即脚本本身）：

```
<base>/
└── <NN_公司>/
    └── 年报PDF/
        └── <公司>_YYYY年年度报告.pdf
```

### 运行

```bash
# 全量：遍历 <base> 下每个公司子文件夹，产出各自 MD
$PY references/extract_chairman_mda.py --base "/path/到/公司根目录"

# 只处理一家公司
$PY references/extract_chairman_mda.py --base "/path" --company 01_国电电力

# 只探测页区、不落盘（先验证定位准不准）
$PY references/extract_chairman_mda.py --base "/path" --dry
```

### 质量验收

```bash
$PY references/audit_md_quality.py --base "/path/到/公司根目录"
```

## 两阶段原理（重要，别只做阶段一）

> 🔴 **必须走完两阶段。** 阶段一 = 抽取底稿，**阶段二 = 结构化重整**。
> 只把 PDF 原始逐行文本倒出来（断行碎片 + 双语英文）不算完成。

- **阶段一（脚本）**：`extract_chairman_mda.py` 用 PyMuPDF 定位章节起止页。
- **阶段二（脚本）**：`tidy_extract.py` 用 pdfplumber 做可读化重整。

本 skill 把两阶段都脚本化了，一条命令产出终稿。

## 输出结构

每份年报一个独立文件，位于公司目录下的专属子文件夹 `董事长致辞与MD&A/`：

```
# <公司> · <年份> 年年度报告 · 董事长致辞与管理层讨论与分析

> 来源 / 抽取范围（董事长致辞 + 管理层讨论与分析）/ 已做可读化重整 / 只保留中文 / 说明 / 局限

### 董事长致辞（主席報告 / 致股东）
> 抽取范围：第 X–Y 页（命中标题「…」）
<可读正文，标题为 #### / #####>

### 管理层讨论与分析
> 抽取范围：第 X–Y 页（命中标题「…」）
<可读正文>
```

- 一家公司 = 多个年份文件（1 年 1 文件），不合并为单文件；
- 未找到的章节**如实标注**「【未找到该章节…】」，绝不虚构（0 幻觉）。

## 技术亮点（踩坑清单）

以下每条都是真实年报里踩出来的坑，改脚本前务必读 `SKILL.md` 的 §4 完整版。节选最关键几条：

1. **简繁 `[节節]` 字符类**：港股繁体「第 X 節」的「節」必须纳入正则，否则全漏。
2. **TOC 跳过**：港股目录是「页码在前」格式（`10主席報告`），要专门判。
3. **防重叠**：港股双报告合并扉页，MD&A 起点落在董事长区间内时要从董事长结束页后重搜。
4. **幻影表（最坑）**：装饰框越出页面 >5pt 会被 pdfplumber 造成「整页假表」，
   后果是整页文字被错位切乱 + 整页正文丢失。必须过 `_table_ok` 三道判据，被拒的表**不剔 bbox**，让文字回落正文。
5. **去英文双栏**：用「两侧各 ≥8 词」平衡判据，且**行级 + 段级两次过滤**。
6. **段落分段**：缩进为主、行距为辅；**左边距取 x0 众数，绝不取 min**。
7. **logo 水印**：「中↔英高频交错行」+「孤立单字符成串」双判据剔除。
8. **字符三连叠印**：判据必须用 **≥3 连续同字**（`(.)\1{2,}`），绝不可用 ≥2，否则误删 `国电电力` 等合法专名。

## 质量验收（交付前必过）

`references/audit_md_quality.py` 一键批量质检，逐家明细 + 全库合计。**五项硬伤任一 >0 即需复核**：

- **英文残留行 = 0**（≥6 英文词且全行无中文）
- **反序页眉 = 0**
- **字符重复 = 0**（≥3 连续同字）
- **纯符号行 = 0**（脚本已白名单 `---` 分隔线、`|---|` 表格行，否则误报数千条）
- **结构覆盖**：董事长致辞命中率 ≈30–40%（A 股多数无独立致辞章，属正常）；MD&A 命中率应接近 100%

🚨 **必查幻影表回归**：若某家英文行数异常偏高，先怀疑整页被幻影表吞掉——
统计 MD 中以 `|` 开头的行占比，正常 <5%，骤高即中招。

## 已知局限

- ✅ 文字层 PDF（PyMuPDF / pdfplumber 可提取）；❌ 扫描版 / OCR 不做。
- ❌ 不做单位归一（千元 / 万元 → 元），那是 `pdf-annual-report-md` 的职责，本 skill 保原文口径。
- 极少数「数据概览 / 图版」页为多表拼版，pdfplumber 还原不出，文字顺序可能乱；
  输出 MD 头已注明「以源 PDF 页码回查」。
